3. O que preencher no Wealthfolio

  1. Settings → Market Data: o provider cdb-brasil-bcb já deve existir (criar uma única vez, ver docs/05).
  2. Novo ativo: symbol canônico · tipo Equity · moeda BRL · exchange MANUAL · quote mode MARKET.
  3. Aba Market Data do ativo: provider cdb-brasil-bcb com symbol override .
  4. Atividade de compra (BUY): data usando o seletor de calendário (digitar 11/09 pode virar 9 de novembro) · unitPrice · quantity .
  5. Conferir: o valor da posição deve bater com o valor bruto do app do banco, a centavos.
